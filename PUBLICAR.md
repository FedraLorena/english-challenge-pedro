# Compartir English Challenge - Unit 4

El proyecto ya es un sitio estático: no necesita servidor de aplicaciones, base de datos, compilación ni claves. No se publicó nada ni se modificó ninguna cuenta.

## Opción gratuita: GitHub Pages

Vas a necesitar una cuenta personal gratuita de GitHub para publicar. Pedro no necesita cuenta para abrir el enlace.

1. Ingresá a [GitHub](https://github.com/) y creá un repositorio nuevo llamado `english-challenge-unit-4`. Elegí **Public** para usar Pages con el plan gratuito.
2. En el repositorio, elegí **Add file → Upload files**. Subí estos seis archivos a la raíz (sin una carpeta contenedora): `index.html`, `styles.css`, `questions.js`, `report.js`, `app.js` y `.nojekyll`. Confirmá con **Commit changes**. Si Windows oculta `.nojekyll`, podés crearlo en GitHub con **Add file → Create new file**, con ese nombre y sin contenido.
3. Entrá a **Settings → Pages**. En **Build and deployment**, elegí **Deploy from a branch**.
4. En **Branch**, seleccioná `main` y la carpeta **/(root)**. Presioná **Save**.
5. Esperá a que termine la publicación. En esa misma pantalla aparecerá el enlace del sitio, con un formato como `https://TU-USUARIO.github.io/english-challenge-unit-4/`. Copiá el enlace real que te muestre GitHub y compartilo con Pedro.
6. Probalo desde el celular: respondé una pregunta, intentá finalizar, comprobá la advertencia y descargá el PDF después de finalizar.

Para actualizarlo después, subí los archivos modificados al mismo repositorio. Pages volverá a publicar los cambios. No hace falta comprar un dominio ni contratar un plan pago para este uso.

El repositorio y el sitio serán públicos. Publicá solamente los archivos de la aplicación: los informes descargados y los resultados de Pedro no se suben automáticamente a GitHub ni se envían a nadie. El PDF se genera en el dispositivo y se comparte manualmente. El enlace necesita internet para cargar la web; la copia local sigue funcionando sin internet, incluido el PDF. La web no instala un modo offline para futuras visitas.

Fuente oficial, consultada el 31/10/2026: [Crear un sitio de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
